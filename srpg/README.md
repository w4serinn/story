# SRPGプロトタイプ「翠嵐と幽闇」

ストーリーリポジトリの設定（characters.md / world_setting.md）を元にしたシミュレーションRPGの縦切りプロトタイプ。

## 遊び方

`prototype.html` をブラウザで開くだけ（依存なしの単一ファイル）。

## 内容

- **シナリオ**: 収穫祭の夜・工房街防衛戦（story_progress の収穫祭護衛訓練が元ネタ）
- **ユニット**: デューク＋セリア vs セレイテッドダーク実行部隊4体（剣士×2・射手・術師）
- **検証したいシステム**:
  - 属性相性（world_setting.md セクション3.7 の属性特性を数値化: 雷→鋼×1.5、風→火×1.25、火→風×0.75）
  - ブレードシフト／稲魂（4マス以内の空きマスへ転移＋隣接雷撃）
  - 影システム（セリアが影マスで被ダメ×0.7・MP−1、シャドウライズは影上の敵に威力+3）
  - 状態異常（シャドウライズ=浮遊、グラヴィティスネア=拘束）

## プロトタイプ仕様（意図的な簡略化）

- 反撃なし、命中率100%、乱数なしの確定ダメージ
- 敵AIは「攻撃可能ならHPの低い方を攻撃、不可なら最近接の味方へ接近」のみ
- 成長・装備・センティエントウェポン覚醒などは未実装（次段階の候補）
